# Semantic Editor Policy v1 — ChatGPT-in-the-loop

The ChatGPT conversation is the ONLY semantic reasoning worker. The Python module
DOES NOT call a model/API, run unattended semantic analysis, or pretend to have
read a video it has not inspected. The user prompts ChatGPT; ChatGPT must invoke
Remote Desktop Commander to read request.json and images, then write a response
and explicitly run submission/validation. Changes to this file invalidate old jobs.

## Contract
- Locked delivery: native 720x1280 / 30 fps / H.264 + AAC. No 1080p output.
- Use the project's recorded Storytelling Code WTS and REN principles when accessible.
- Every beat has WHO/WANT as relevant, causal TAPI→SO, meaningful open question and payoff.
- Preserve source meaning. DO NOT misquote speech, fabricate studies or remove context.
- Group a complete sentence/idea, NOT individual nouns. One B-roll may span multiple lines.
- Every source segment must be covered or explicitly excluded with an editorial reason.
- Asset selections must reference known asset IDs with VERIFIED licenses; no invented footage.
- For headlines: editor chooses copy, then choose NONE/AUTO/BOXED/OUTLINE; never force one.
  Prefer black bold in white rounded box when space is clean and contrast supports it.
  Prefer white bold with dark outline when busy; adjust after actual frame contrast analysis.
  Protect TikTok UI overlays, face and hair, source subtitles and important objects.
  Font measurements, exact pixel bounds and dynamic safe-zone pass are separate QA gates.
  NEVER cover/remask an existing burned-in headline unless a visually clean method exists.
- Dynamics: STATIC or 100–103% SUBTLE or up to 105% EMPHASIS, attached to narrative beat.
  Never apply a repeating zoom automatically across every sentence; protect crop and text.
- Do not invent millisecond word timestamps. Cut guidance is only
  KEEP/TRIM_SILENCE/REVIEW until waveform/VAD and listening QA proves boundaries.
- A frame file may be inspected through Desktop Commander; a path is not evidence of
  having visually reviewed the frame. No frames => no face-safe placement approval.
- Private semantic VALIDATED does not mean story, creative, source rights or publication
  APPROVED. Publishing requires separate rights and human review gates.
- Record uncertainty and negative/neutral choices honestly.
